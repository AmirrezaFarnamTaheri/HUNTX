    03 What worked?

    Test a neutral HTTPS page through the selected proxy in your client, with certificate verification enabled. A browser loading directly, a ping, or an imported subscription does not confirm recovery.

    Only the selected device category, network type, symptom and outcome are included. No proxy URI, credentials, SSID, IP or browsing history are collected.

    What counts as recovered?

    Original proxy restored: The same endpoint connects successfully in your proxy client after a safe change.

    Alternative found: A different endpoint works, but the original may still be unavailable.

    A published subscription or a successful metadata request is not a connectivity test.

    Safety first

    Do not disable certificate verification, guess server names, or replace cryptographic credentials.

    Try changes one at a time and revert them if they do not help. Compare Wi-Fi and mobile data where available.
